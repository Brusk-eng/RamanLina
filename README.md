# Raman & Lina Wedding Invitation

A luxury animated digital wedding invitation for **Raman & Lina**, built with HTML, CSS, and vanilla JavaScript. Hosted on GitHub Pages.

## Wedding Details

- **Date:** Sunday, 06 September 2026 at 7:00 PM (Asia/Baghdad)
- **Venue:** White Hall Erbil, Big Ballroom
- **Address:** Next to Social Academic Center, Erbil, Erbil Governorate 44001, Iraq
- **Map:** [White Hall Erbil](https://maps.app.goo.gl/qM9R4CKw6C7FyEYA9)

## Features

- Language portal (English / Kurdish / Arabic)
- Animated olive gates
- Islamic blessing
- Live countdown timer
- Invitation ticket
- Venue section with Google Maps
- Floating music button (same track as the original invitation)
- Mobile-first luxury design

## How to Run Locally

Open `index.html` in a browser. No build step required.
